# 今天怎么吃 · v6.1 我的小宇宙手帐版

本版本在 v5 外观 DIY 基础上新增「我」模块：

- 一个独立的秘密小宇宙入口
- 富文本手帐编辑器
- 粗体、斜体、下划线
- 荧光笔
- 文字颜色
- 字体风格选择
- 字号选择
- 插入图片
- 批注
- 每次保存的内容会变成一颗随机散落的记忆星星
- 点击星星可以查看记忆详情

替换 GitHub 文件：
- index.html
- styles.css
- app.js
- sw.js
