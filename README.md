# 今天怎么吃 · 手机版莫兰迪 PWA 原型

这是一个手机优先的本地网页应用原型，用来记录减脂期间的饮食、食材清单、想吃清单、拍照记录和心情日记。

## 特点

- 莫兰迪配色
- 手机优先界面
- 底部导航栏
- 卡片式 UI
- 本地保存数据：使用浏览器 localStorage
- 不需要数据库、不需要服务器
- 可以作为 PWA 基础继续升级

## 本地运行方法

进入项目文件夹后运行：

```bash
python3 -m http.server 5173
```

然后浏览器打开：

```text
http://localhost:5173
```

Mac 如果 `python3` 不可用，可以试：

```bash
python -m http.server 5173
```

## 手机预览

本地运行后，如果手机和电脑在同一个 Wi-Fi，可以用电脑局域网 IP 打开，例如：

```text
http://192.168.1.23:5173
```

注意：真正添加到手机主屏幕，最好之后部署到 HTTPS 网站，例如 Vercel、Netlify 或 GitHub Pages。

## 数据存在哪里

数据保存在当前浏览器的 localStorage 里。换浏览器或清除浏览器数据后会消失。
